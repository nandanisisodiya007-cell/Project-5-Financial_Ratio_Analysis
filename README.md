Project 05 – Financial Ratio Analysis

Project Overview

This project compares the financial performance of two FMCG companies, Marico Limited and Emami Limited, using financial ratio analysis for FY 2025–26.

Companies Analysed

- Marico Limited
- Emami Limited

Project Objectives

- Analyse liquidity ratios.
- Evaluate profitability ratios.
- Examine financial leverage.
- Measure operational efficiency.
- Compare the financial performance of both companies.

Ratios Calculated

A total of 12 financial ratios were calculated:

1. Current Ratio
2. Quick Ratio
3. Operating Profit Margin
4. Net Profit Margin
5. Return on Equity (ROE)
6. Debt-to-Equity Ratio
7. Interest Coverage Ratio
8. Asset Turnover Ratio
9. Inventory Turnover Ratio
10. Gross Profit Margin
11. Equity Ratio
12. Working Capital Turnover Ratio

Tools Used

- Microsoft Excel
- Financial Ratio Analysis
- GitHub

Project Files

- "Project_5_Completed.xlsx" – Financial data, formulas, ratio calculations and company comparison.
- "Project_5_Interpretation_Note.pdf" – Financial interpretations, comparison, conclusion and limitations.

Conclusion

The analysis indicates that Emami performs better in liquidity, profit margins and selected leverage measures, while Marico performs better in return on equity and efficiency ratios.

The findings are educational and do not constitute investment advice.
